# SNP — Something New Pic

iPhone 기본 카메라의 조작 감각은 그대로, 결과물은 iPhone 5s~6s 세대에 맞춘 카메라 앱.

## 열기

1. Finder 에서 `SNPCam.xcodeproj` 더블클릭
2. 좌측 상단 타깃 `SNPCam` → Signing & Capabilities 탭
3. **Team** 을 본인 Apple ID 로 선택 (무료 계정도 가능)
4. **Bundle Identifier** 를 고유한 값으로 변경 (예: `com.내이름.snpcam`)
5. 아이폰을 USB 로 연결 → 기기 선택 → ⌘R

> 카메라는 시뮬레이터에서 동작하지 않습니다. 반드시 실기기에서 실행하세요.
> 무료 개발자 계정은 앱이 7일마다 만료되며, 재설치하면 다시 사용할 수 있습니다.

- 최소 지원: **iOS 17**
- 방향: 세로 고정

## 프레임

| 모드 | 비율 | 저장 해상도 (5s·5s+·OFF) | 저장 해상도 (6s·6s+) |
|---|---|---|---|
| 5:5 (기본) | 1:1 정사각 | 2448 × 2448 | 3024 × 3024 |
| 4:3 | 세로 3:4 | 2448 × 3264 | 3024 × 4032 |

두 비율 모두 4:3 센서에서 나오며, 5:5 는 가운데를 잘라 씁니다.
저장 해상도는 흉내내는 기종의 센서에 맞춰 다운스케일합니다 — 5s 는 8MP(3264×2448), 6s 는 12MP(4032×3024).
룩의 블러·샤프닝·그레인 반경은 해상도에 비례해 스케일되므로, 해상도가 달라져도 결의 느낌은 유지됩니다.

## 조작

| | |
|---|---|
| 화면 탭 | 그 지점에 초점 + 측광 |
| 길게 누르기 | 초점/노출 초기화 |
| 하단 슬라이더 | 노출 보정 (±EV) |
| 상단 좌측 | 플래시 (끔 / 자동 / 켬), 타이머 (끔 / 3초 / 10초) |
| 상단 우측 | 3분할 그리드, 수평계 |
| 하단 칩 | 비율 전환 (5:5 ↔ 4:3), 룩 전환 (5s → 5s+ → 6s → 6s+ → OFF) |
| 셔터 위 글자 | 모드 전환 (비디오 / 사진) |
| 좌측 하단 썸네일 | 사진 앱 열기 |

타이머 카운트다운 중에 셔터를 다시 누르면 취소됩니다.

## 비디오 (캠코더)

셔터 위 **비디오** 를 누르면 녹화 모드가 됩니다. 사진과 같은 두 비율, 같은 룩이 그대로 걸립니다.

| 비율 | 저장 해상도 |
|---|---|
| 5:5 | 1080 × 1080 |
| 4:3 | 1080 × 1440 (세로) |

- H.264 `.mov`, 30fps 안팎, 소리 포함 (마이크 권한을 거부하면 소리 없이 녹화)
- 녹화 중에는 상단 가운데에 녹화 시간이 뜨고, 비율 전환·카메라 전환은 잠깁니다. 룩은 녹화 중에도 바꿀 수 있습니다
- 플래시 버튼은 비디오에서 조명(토치)으로 동작합니다 — 녹화를 시작할 때 켜지고 끝나면 꺼집니다
- 타이머를 켜 두면 카운트다운 후 녹화가 시작됩니다
- 앱을 벗어나면 녹화가 끝나고 보관함에 저장됩니다
- 마이크는 비디오 모드에서만 연결합니다 — 사진 모드에서는 마이크 표시등이 켜지지 않습니다

## 룩 — 5s~6s 재현

프리뷰와 저장본에 **완전히 같은 필터 체인**이 걸립니다. 보이는 그대로 찍힙니다.
`SNPCam/Look/LookParameters.swift` 의 숫자만 고치면 전체 톤이 바뀝니다.

| 단계 | 파라미터 | 재현하는 것 |
|---|---|---|
| 화이트밸런스 | `targetTemperature` 5850K, `targetTint` +6 | 차갑고 살짝 마젠타 기운 |
| 채도 | `saturation` 0.88 | 요즘 아이폰보다 옅은 색 |
| 톤 커브 | `blackLift` 0.055, `highlightRolloff` 0.935 | 낮은 다이나믹 레인지 — 들린 블랙, 쉽게 날아가는 하이라이트 |
| 글레어 | `glareAmount` 0.30 | 광원 주변 번짐 (플레어) |
| 소프트 디테일 | `softness` 1.0 → `sharpenIntensity` 0.5 | 광학 해상력 부족 + ISP 샤프닝 헤일로 |
| 그레인 | `grainAmount` 0.55, `grainSize` 2.2, `shadowGrainBias` 0.8 | 8MP 센서 노이즈 (그림자·중간톤에 집중) |
| 비네팅 | `vignetteIntensity` 0.55 | 렌즈 주변부 광량 저하 |
| 센서 | `sensorLongSide` 3264 | 저장 해상도 (3264 = 8MP, 4032 = 12MP) |

위 값은 기본 프리셋(5s) 기준입니다.

### 프리셋

| 칩 | 프리셋 | 느낌 |
|---|---|---|
| 5s | `standard` | iPhone 5s (2013). 차갑고 옅은 색, 들린 블랙, 거친 노이즈 |
| 5s+ | `strong` | 5s 를 과장한 실내 저조도 버전 — 실제 기종이 아님. 더 차갑고 더 거칠고 더 어두운 주변부 |
| 6s | `iPhone6s` | iPhone 6s (2015). 12MP 로 디테일·샤프닝이 늘고 색이 더 진하고 따뜻함. 알갱이가 더 잘음 |
| 6s+ | `iPhone6sStrong` | 6s 를 과장한 실내 저조도 버전 — 실제 기종(6s Plus)이 아님. 더 따뜻하고 더 거칠고 더 어두운 주변부 |
| OFF | `off` | 룩 없음 (원본) |

5s 보다 6s 가 색이 따뜻·진하고, 다이나믹 레인지가 넓고, 노이즈 알갱이가 잘게 잡혀 있습니다.
`+` 프리셋은 각 기종의 성격을 과장한 저조도 버전입니다 — 5s+ 는 더 차갑게, 6s+ 는 더 따뜻하게.
실기기 사진과 나란히 놓고 비교하며 `LookParameters.swift` 의 숫자를 다듬어 주세요.

## 구조

```
SNPCam/
├─ App/        SNPCamApp.swift          앱 진입점
├─ Camera/     CameraManager.swift      세션·촬영·초점·노출
│              PreviewRenderer.swift    Metal 실시간 프리뷰 (필터 적용된 화면)
│              PhotoProcessor.swift     크롭 → 8/12MP 다운스케일 → 룩 → JPEG
│              PhotoCaptureDelegate.swift
│              VideoRecorder.swift      룩 입힌 프레임 + 소리 → .mov
│              FrameRatio.swift
├─ Look/       LookParameters.swift     ← 튜닝은 여기서
│              RetroLook.swift          Core Image 필터 체인
├─ UI/         CameraScreen.swift, Overlays.swift
└─ Support/    MotionManager.swift      수평계
```

기본 카메라처럼 `AVCaptureVideoPreviewLayer` 를 쓰지 않고, `AVCaptureVideoDataOutput` →
Core Image → `MTKView` 로 직접 그립니다. 그래야 프리뷰에도 룩이 걸립니다.
