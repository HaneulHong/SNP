# SNP — Something New Pic

iPhone 기본 카메라의 조작 감각은 그대로, 결과물은 iPhone 5s~6s 세대에 맞춘 카메라 앱.
사진은 35mm 필름 룩(기본)과 5s·6s 룩, 비디오는 옛날 캠코더 룩. 렌즈는 하나만 쓴다.

## 아이폰에서 실행하기

처음 한 번만:

1. **Xcode 에 Apple ID 로그인** — Xcode › Settings › Accounts › `+` › Apple ID (무료 계정 가능)
2. **아이폰 개발자 모드 켜기** — 아이폰 설정 › 개인정보 보호 및 보안 › 맨 아래 **개발자 모드** 켬 → 재시동 → 잠금 해제 후 "켜기"
   (메뉴가 안 보이면 아이폰을 USB 로 연결한 채 Xcode 를 한 번 열어두면 나타난다)
3. Finder 에서 `SNPCam.xcodeproj` 더블클릭 → 좌측 `SNPCam` 타깃 › Signing & Capabilities › **Team** 을 본인 이름(Personal Team)으로
4. 상단 기기 목록에서 연결된 아이폰 선택 → ⌘R
5. 처음 실행 때 "신뢰할 수 없는 개발자" 가 뜨면 아이폰 설정 › 일반 › VPN 및 기기 관리 › 본인 Apple ID › **신뢰**

> 카메라는 시뮬레이터에서 동작하지 않습니다 (화면 배치만 확인 가능). 반드시 실기기에서 실행하세요.
> 무료 개발자 계정은 앱이 7일마다 만료되며, 다시 ⌘R 하면 된다.
> 번들 ID `com.haneulhong.snpcam` 이 이미 쓰인다는 오류가 나면 끝에 아무 글자나 붙여 바꾸면 된다.

- 최소 지원: **iOS 17**
- 방향: 세로 고정

## 렌즈 하나 — 옛날 아이폰처럼

요즘 아이폰은 후면 카메라가 2~3개고, 줌·접사 때 렌즈를 알아서 바꾼다.
이 앱은 **메인 광각 물리 렌즈 하나만** 쓰고 (`LegacyLens.swift`), 렌즈를 바꾸는 가상 멀티카메라는 절대 쓰지 않는다.

- **화각 고정** — 6/6s 후면은 35mm 환산 29mm, 요즘 메인은 24~26mm 로 더 넓다.
  가운데를 디지털로 잘라 29mm 화각에 맞춘다 (14 Pro 기준 ×1.21). 전면은 FaceTime HD 31mm 에 맞춘다.
  잘라도 5s 룩의 저장 해상도(8MP)보다 센서 픽셀이 많아서 화질 손해는 없다. 6s 룩(12MP)은 12MP 센서 기기에서 조금 확대된다.
- **FILM 룩은 35mm** — 레퍼런스 사진을 찍은 Leica minilux zoom(35–70mm)의 광각 끝에 맞춘다. 더 좁은 화각이라 원근 왜곡이 적고 거리감이 자연스럽다. 룩을 바꾸면 프리뷰 화각도 같이 바뀐다 (비디오는 29mm).
- **줌 없음** — 핀치 줌, 0.5×/3× 버튼 없음. 발로 움직인다.
- 전면 센터 스테이지(자동 프레이밍), 비디오 HDR 끔.

## 비디오 — 캠코더 룩

셔터 위 **비디오 / 사진** 을 눌러 전환. 비디오는 SD 480줄 30fps 로 기록되고 사진 보관함에 저장된다.
비율은 사진과 같은 두 가지다.

| 비율 | 세로로 들고 녹화 | 가로로 들고 녹화 |
|---|---|---|
| 5:5 | 480 × 480 | 480 × 480 (가로 방향으로 기록) |
| 4:3 | 480 × 640 | 640 × 480 |

**폰을 가로로 들고 녹화 버튼을 누르면 가로 영상**으로 기록된다. 녹화 도중엔 방향과 비율이 고정된다.

| | |
|---|---|
| 하단 칩 `5:5` / `4:3` | 비율 전환 (사진과 공통) |
| 하단 칩 `DV` / `VHS` / `OFF` | 룩 전환 |
| 하단 칩 `DATE` | 오른쪽 아래 날짜 스탬프 (`10:16:32 PM` / `SEP. 25 2026`) |
| 상단 좌측 | 손전등 (후면만) |

프리뷰와 파일에 **같은 프레임**을 쓴다 — 보이는 그대로 기록된다. `SNPCam/Look/CamcorderParameters.swift` 에서 튜닝.

| 단계 | 파라미터 | 재현하는 것 |
|---|---|---|
| CCD 색 | `targetTemperature`, `targetTint`, `saturation` | DV: 따뜻하고 쨍함 / VHS: 물 빠지고 마젠타 |
| 비디오 레인지 | `blackLift`, `whiteLevel`, `contrast` | 뜬 블랙, 쉽게 하얗게 날아가는 하이라이트 |
| 렌즈 | `softness`, `vignetteIntensity` | 해상력 부족, 주변부 어두움 |
| 센서 노이즈 | `noiseAmount`, `chromaNoise`, `noiseStretch` | 매 프레임 지글거리는 노이즈 (VHS 는 가로로 늘어진 테이프 노이즈) |
| 에지 강조 | `edgeEnhance`, `edgeRadius` | 경계의 하얀 테두리 — 캠코더 DSP 특유 |
| 날짜 스탬프 | — | 도트 폰트. 테이프에 같이 기록된 것처럼 아래 번짐을 같이 먹는다 |
| 테이프 | `chromaBleed`, `chromaShift` | 색이 가로로 흘러내리고 오른쪽으로 밀림 |
| 인터레이스 | `scanlines` | 가는 가로줄 |
| 트래킹 | `jitter` | VHS 의 가로 흔들림 |

소리는 마이크로 함께 녹음한다 (권한 거부 시 무음으로 기록). 사진 모드에선 마이크를 놓는다.

## 프레임

| 모드 | 비율 | 저장 해상도 (FILM·5s·5s+·OFF) | 저장 해상도 (6s·6s+) |
|---|---|---|---|
| 5:5 (기본) | 1:1 정사각 | 2448 × 2448 | 3024 × 3024 |
| 4:3 | 세로 3:4 | 2448 × 3264 | 3024 × 4032 |

두 비율 모두 4:3 센서에서 나오며, 5:5 는 가운데를 잘라 씁니다.
저장 해상도는 흉내내는 기종의 센서에 맞춰 다운스케일합니다 — 5s 는 8MP(3264×2448), 6s 는 12MP(4032×3024).
셀카(전면 카메라)는 그 시절 전면 카메라 해상도로 저장합니다 — 5s 는 1.2MP(960×1280), 6s 는 5MP(1932×2576). FILM·OFF 는 셀카도 8MP.
룩의 블러·샤프닝·그레인 반경은 해상도에 비례해 스케일되므로, 해상도가 달라져도 결의 느낌은 유지됩니다.

## 룩 — 5s~6s 재현

프리뷰와 저장본에 **완전히 같은 필터 체인**이 걸립니다. 보이는 그대로 찍힙니다.
예외는 세 가지 — 플래시가 터진 사진의 플래시 룩, 셀카의 저해상도 저장, FILM 의 심도(배경 흐림) — 로, 찍는 순간에만 계산하므로 저장본에만 걸립니다.
`SNPCam/Look/LookParameters.swift` 의 숫자만 고치면 전체 톤이 바뀝니다.

| 단계 | 파라미터 | 재현하는 것 |
|---|---|---|
| 화이트밸런스 | `targetTemperature` 5850K, `targetTint` +6 | 차갑고 살짝 마젠타 기운 |
| 채도 | `saturation` 0.88 | 요즘 아이폰보다 옅은 색 |
| 톤 커브 | `blackLift` 0.055, `highlightRolloff` 0.935, `midGamma` 1.0 | 낮은 다이나믹 레인지 — 들린 블랙, 쉽게 날아가는 하이라이트. `midGamma` > 1 이면 중간톤이 가라앉음 |
| 필름 색 | `filmColor` 0 (FILM 1.0) | 35mm 필름 색 LUT — 진한 빨강·노랑, 올리브 초록, 청록 파랑, 크림빛 하이라이트 (`FilmColor.swift`) |
| 글레어 | `glareAmount` 0.30 | 광원 주변 번짐 (플레어) |
| 할레이션 | `halation` 0 (FILM 0.25) | 아주 밝은 곳 가장자리의 붉은 주황 번짐 |
| 헤이즈 | `hazeAmount` 0.25, `hazeRadius` 14 | 뿌연 화질 — 흐린 사본의 밝은 쪽만 섞어 잡티를 묻고 피부를 뽀얗게 |
| 소프트 디테일 | `softness` 1.0 → `sharpenIntensity` 0.5 | 광학 해상력 부족 + ISP 샤프닝 헤일로 |
| 그레인 | `grainAmount` 0.55, `grainSize` 2.2, `shadowGrainBias` 0.8 | 8MP 센서 노이즈 (그림자·중간톤에 집중) |
| 비네팅 | `vignetteIntensity` 0.55 | 렌즈 주변부 광량 저하 |
| 심도·거리감 | `depthBlur` 0 (FILM 12), `depthHaze` 0 (FILM 0.10) | 사람 뒤 배경만 흐리고 옅게 (`DepthEffect.swift`, 저장본만) |
| 센서·렌즈 | `sensorLongSide` 3264, `frontSensorLongSide` 1280, `focalLength` 29 (FILM 35) | 저장 해상도 (3264 = 8MP, 4032 = 12MP) / 셀카 저장 해상도 (1280 = 1.2MP, 2576 = 5MP) |

위 값은 기본 프리셋(5s) 기준입니다.

### 프리셋

| 칩 | 프리셋 | 느낌 |
|---|---|---|
| FILM (기본) | `film` | Leica minilux zoom + 35mm 컬러 필름. 35mm 화각, 진하지만 부드러운 색, 황금빛 피부, 사람 뒤 배경은 살짝 흐리고 옅게, 고운 그레인, 8MP |
| 5s | `standard` | iPhone 5s (2013). 차갑고 옅은 색, 들린 블랙, 거친 노이즈 |
| 5s+ | `strong` | 5s 를 과장한 실내 저조도 버전 — 실제 기종이 아님. 더 차갑고 더 거칠고 더 어두운 주변부 |
| 6s | `iPhone6s` | iPhone 6s (2015). 12MP, 어둡고 따뜻한 저채도 "느좋" 색감. 과한 샤프닝 없음. 알갱이가 더 잘음 |
| 6s+ | `iPhone6sStrong` | 6s 를 과장한 실내 저조도 버전 — 실제 기종(6s Plus)이 아님. 더 따뜻하고 더 거칠고 더 어두운 주변부 |
| OFF | `off` | 룩 없음 (원본) |

5s 는 차갑고 바랜 색, 6s 는 어둡고 따뜻한 색으로 두 방향을 나눴습니다. 6s 가 다이나믹 레인지가 넓고 노이즈 알갱이도 더 잡니다.

**FILM 의 심도** — 폰은 센서가 작아 배경까지 선명하게 찍힙니다. FILM 은 Vision 의 사람 분리 마스크로
사람 뒤 배경만 흐리고(`depthBlur`), 먼 곳처럼 옅게(`depthHaze`) 만들어 필름 카메라의 거리감을 냅니다.
사람이 없거나 아주 작게 찍힌 사진(풍경·정물)은 그대로 선명하게 두고, 사람이 화면을 크게 차지할수록(가까울수록) 배경을 더 흐립니다.
minilux zoom 은 f/3.5~6.5 로 어두운 렌즈라 배경이 크게 녹지 않으므로, 흐림은 "살짝 부드러운" 정도로 약하게 잡았습니다.
다른 프리셋에도 `depthBlur` 값을 주면 같은 효과가 걸립니다.
`+` 프리셋은 각 기종의 성격을 과장한 저조도 버전입니다 — 5s+ 는 더 차갑게, 6s+ 는 더 따뜻하게.
실기기 사진과 나란히 놓고 비교하며 `LookParameters.swift` 의 숫자를 다듬어 주세요.

### 요즘 옛날 아이폰을 사진기로 쓰는 이유 → 반영한 것

2025~2026 국내외 "영트로(young + retro)" 유행에서 반복해서 나오는 이유를 룩에 옮겼습니다.

| 사람들이 옛날 아이폰을 찾는 이유 | 반영 |
|---|---|
| 뿌연 화질이 잡티를 가려서 보정 없이도 얼굴이 부드럽다 | 모든 룩에 **헤이즈** (`hazeAmount`) |
| 요즘 아이폰은 너무 선명하고 파랗다 — "어둡고 따뜻한 저채도" 가 느좋 | **6s·6s+** 를 더 따뜻하고 어둡게 (`targetTemperature`, `midGamma`), 샤프닝은 약하게 |
| 2010년대 플래시 셀카·파티 사진 감성 | **플래시 룩** — 플래시가 실제로 터진 사진만 얼굴은 하얗게, 가장자리는 어둡게, 반짝이는 것은 번지게 (`withFlash()`) |
| 옛날 전면 카메라의 저화질 셀카 | **셀카 저해상도 저장** — 5s·5s+ = 1.2MP, 6s·6s+ = 5MP (`frontSensorLongSide`) |
| 노이즈·빛 번짐이 필름 같다 | 기존 그레인·글레어 유지 |

## 구조

```
SNPCam/
├─ App/        SNPCamApp.swift          앱 진입점
├─ Camera/     CameraManager.swift      세션·모드 전환·촬영·녹화·초점·노출
│              LegacyLens.swift         렌즈 하나 고정 + 5s~6s 화각
│              PreviewRenderer.swift    Metal 실시간 프리뷰 (필터 적용된 화면)
│              PhotoProcessor.swift     크롭 → 8/12MP 다운스케일 → 룩 → JPEG
│              PhotoCaptureDelegate.swift  (+ 플래시 룩, 보관함 저장)
│              VideoRecorder.swift      룩 입힌 프레임 + 소리 → .mov
│              CaptureMode.swift        사진/비디오, 기록 방향
│              FrameRatio.swift
├─ Look/       LookParameters.swift     ← 사진 튜닝은 여기서
│              RetroLook.swift          사진 필터 체인
│              FilmColor.swift          35mm 필름 색 LUT
│              DepthEffect.swift        사람 뒤 배경 흐림·공기감
│              CamcorderParameters.swift ← 비디오 튜닝은 여기서
│              CamcorderLook.swift      비디오 필터 체인 + 날짜 스탬프
├─ UI/         CameraScreen.swift, Overlays.swift
└─ Support/    MotionManager.swift      수평계 + 기기 방향
```

기본 카메라처럼 `AVCaptureVideoPreviewLayer` 를 쓰지 않고, `AVCaptureVideoDataOutput` →
Core Image → `MTKView` 로 직접 그립니다. 그래야 프리뷰에도 룩이 걸립니다.
비디오도 같은 이유로 `AVCaptureMovieFileOutput` 대신 `AVAssetWriter` 로 프레임을 직접 인코딩합니다.
